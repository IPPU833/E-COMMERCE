# E-COMMERCE

A modern, responsive e-commerce web application built with HTML, CSS, and JavaScript. This project showcases a fully functional online shopping platform with an intuitive user interface and smooth user experience.

## 🌟 Features

- **Responsive Design** - Mobile-friendly layout that works seamlessly on all devices
- **Product Catalog** - Browse and explore a variety of products
- **Shopping Cart** - Add/remove items and manage quantities
- **User-Friendly Interface** - Intuitive navigation and clean design
- **Fast & Lightweight** - Pure HTML, CSS, and JavaScript with no external dependencies
- **Modern Web Standards** - Built with semantic HTML and best practices

## 🛠️ Technology Stack

| Language | Usage | Percentage |
|----------|-------|-----------|
| **HTML** | Structure & Content | 89.1% |
| **CSS** | Styling & Layout | 9.8% |
| **JavaScript** | Interactivity & Logic | 1.1% |

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/IPPU833/E-COMMERCE.git
   cd E-COMMERCE
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or visit: [https://ippu833.github.io/E-COMMERCE/](https://ippu833.github.io/E-COMMERCE/)

## 💡 Usage

1. **Browse Products** - Navigate through the product catalog
2. **Add to Cart** - Click "Add to Cart" on any product
3. **View Cart** - Access your shopping cart to see selected items
4. **Checkout** - Proceed with the purchase process

## 🎨 Features Breakdown

### Responsive Design
The application adapts to different screen sizes:
- Desktop (1024px and above)
- Tablet (768px - 1023px)
- Mobile (below 768px)

### Interactive Elements
- Dynamic cart updates
- Product filtering and search
- Real-time price calculations
- Smooth animations and transitions

## 🔧 Customization

### Adding Products
Edit the product data in `js/script.js` to add more products:
```javascript
const products = [
  { id: 1, name: "Product Name", price: 99.99, image: "image.jpg" },
  // Add more products here
];
```

### Styling
Modify `css/styles.css` to customize:
- Color schemes
- Font sizes and typography
- Layout and spacing
- Animations
